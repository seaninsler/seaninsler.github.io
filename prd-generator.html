What this is

Most PRDs start with a blank page and a vague mandate. This tool removes the blank page. You give it the product and the problem, and it returns a first draft with the sections a real PRD needs: problem framing, goals and non-goals, users, functional requirements, success metrics, risks, open questions, and milestones.

It drafts in two passes on purpose. The first pass diagnoses and frames the problem. The second pass structures the build. That mirrors how I work through ambiguous product problems: intake, diagnose, synthesize, structure, ship. It produces a strong starting draft. You still own the decisions.

How it works

The front end is plain HTML and JavaScript, no framework and no build step. It calls the Anthropic API directly and runs generation as two sequential calls, so each set of sections comes back as clean, structured JSON and renders into the document.

Auth is bring-your-own-key. Your API key stays in your browser for the session, goes straight to Anthropic, and is never stored, logged, or sent anywhere else. Direct browser calls are fine for a personal demo like this. A production version would route through a small server so no key is ever exposed.

Try it

Get a key at console.anthropic.com. It is used only to call Anthropic directly from this page.

Take it

Two ways to run it yourself.

1. In Claude, no key needed

Copy the Claude-ready version, open a new chat at claude.ai, and paste it in. Claude renders it as an artifact and handles the API call, so it runs with no key.

2. Standalone, with your own key

Download this page and open it anywhere. It works the same, using your own Anthropic key.
